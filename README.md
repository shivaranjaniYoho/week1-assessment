# HR Employee Data Analysis

Project status: Analysis completed and ready for review.

## Project Overview
This project analyses employee information using Python, Pandas, NumPy and Matplotlib.

## Project Structure
- `data/` – Employee and department CSV files.
- `notebooks/` – Jupyter Notebook and exported Python script.
- `reports/` – Supporting files.
- `src/` – Source code.

## Setup Instructions

1. Install Python.
2. Install the required libraries:

```bash
python -m pip install pandas numpy matplotlib jupyter nbconvert
```

3. Open the project folder in VS Code.
4. Open `notebooks/hr_analysis.ipynb`.
5. Run the notebook cells.

## Key Findings

1. The dataset contains 10 employees.
2. There are three departments: IT, HR and Finance.
3. Five employees belong to Chennai.
4. The average employee salary is 37,600.
5. IT has the highest average salary.
